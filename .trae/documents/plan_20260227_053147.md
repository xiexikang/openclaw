# 在 MFA 认证页面添加刷新二维码功能

用户希望在二维码下方添加一个按钮，用于刷新验证码。

## 计划步骤

1.  **修改 `src/server.ts`**
    -   引入 `dabbyClient`。
    -   添加 `/mfa-auth/refresh` POST 路由。
    -   实现刷新逻辑：验证 Session -> 调用 `dabbyClient.getQrCode()` -> 更新 Session 数据 -> 返回新的二维码内容和过期时间。

2.  **修改 `src/providers/qr-code.ts`**
    -   **HTML 结构**：在二维码图片下方添加一个“刷新二维码”按钮。
    -   **CSS 样式**：为按钮添加样式（如 `.refresh-btn`），使其美观且易于点击。
    -   **JS 逻辑**：添加 `refreshQrCode` 函数，调用后端刷新接口，成功后更新图片 `src`、重置倒计时并重新开始轮询状态。

3.  **验证**
    -   重启服务。
    -   打开认证页面，点击“刷新二维码”按钮，确认二维码图片更新，且新二维码可正常扫码认证。
